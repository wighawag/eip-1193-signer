# @eip-1193/signer

A local [EIP-1193](https://eips.ethereum.org/EIPS/eip-1193) signer backed by a private key or mnemonic (via viem), plus helpers that wrap an existing provider so signing requests are handled locally.

```bash
npm install @eip-1193/signer
```

Formerly published as `eip-1193-signer`.
